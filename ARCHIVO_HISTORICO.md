# Archivo histórico de la entrega

El repositorio contiene el código Python completo, los iniciadores de Windows, todos los recursos de ejecución (sprites, fondos, mapa, efectos y audio), las políticas, los datos CSV/JSON/SVG y los informes.

Las 340 imágenes, animaciones y videos de diagnósticos de versiones anteriores se conservan en el ZIP completo de la versión v0.22 en [Releases](https://github.com/xZero-exe/Digimon-RPG-COM50100/releases). Las capturas actuales de v0.22, las figuras del informe y del balance actual también están en este repositorio.

`resultados/publicacion_v022/archivos_publicacion.json` identifica los archivos del **ZIP completo**, incluidas esas capturas históricas. Los hashes del modelo, las imágenes utilizadas por el juego, los algoritmos y las políticas son iguales en ambas distribuciones. El README del repositorio añade esta explicación de distribución.

Para ejecutar el juego basta con descargar este repositorio completo, extraerlo y abrir `JUGAR_WINDOWS.bat`. El ZIP de Releases incluye además el archivo visual histórico.
